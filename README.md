# AI 뉴스데스크

AI 업계 뉴스·블로그·결과물 사례를 한 화면에 모으는 로컬 대시보드. 외부 의존성 없음(Node 18+).

    node ai-newsdesk/server.js      # → http://localhost:4577  (PORT 환경변수로 변경)

## 다른 기기(폰·태블릿·다른 PC)에서 열기
같은 Wi-Fi/네트워크 안에서 접속할 수 있습니다. 화면은 폰 크기에도 맞춰집니다.

**Windows:** `AI-Newsdesk.bat` 을 더블클릭하면 끝입니다(서버 시작 + 브라우저 자동 열림, 이미 켜져 있으면 브라우저만 열림). 창을 닫으면 종료됩니다.
**Mac·Linux:** `npm run lan`

실행하면 `다른 기기에서 → http://192.168.x.x:4577` 주소가 출력됩니다. 그 주소를 폰 브라우저에 입력하세요.
- Windows 방화벽이 처음 한 번 허용을 물으면 “개인 네트워크”를 허용하세요.
- 인증이 없어 같은 네트워크의 누구나 열 수 있고 소스 추가·갱신도 할 수 있습니다. 카페 등 공용망에서는 켜지 마세요(기본 실행은 이 PC 전용).
- 집 밖에서 쓰려면 Tailscale 같은 개인 VPN을 쓰는 편이 안전합니다.
- Node 18 이상만 있으면 Windows·Mac·Linux 어디서든 동일하게 동작합니다.

- 첫 실행 시 자동 수집, 이후 설정한 주기(기본 30분)마다 갱신. 화면의 “지금 업데이트”로 즉시 갱신.
- ★ 스터디 보드: 글을 담아 메모/태그/진행상태(읽을 것·학습 중·완료) 관리. `data/study.json`에 저장.
- ⚙ 소스·설정: 소스 켜기/끄기, RSS 추가, 수집 성공/실패 확인. 기본 소스 목록은 `sources.js`.
- 인스타그램·페이스북·쓰레드·X는 로그인 없이 직접 수집할 수 없어 구글뉴스 검색(경유)·Mastodon·HN 등 공개 경로로 대체합니다.
- `data/`(수집 결과·스터디·설정)는 git 에 포함하지 않습니다.

## 중요도 순서와 이미지
- 점수 = 출처 신뢰도 + 주요 기업·사건 키워드 + 여러 매체가 같은 이야기를 보도한 정도(🔥 n개 매체) + 커뮤니티 반응 + 최신성(20시간 반감) + 이미지 보너스. 같은 이야기는 대표 1건만 노출. 계산식은 `rank.js`.
- 이미지는 RSS에 있으면 사용하고, 없으면 기사 페이지의 대표 이미지(og:image)를 업데이트 때 상위 기사부터 가져옵니다(`enrich.js`). 구글뉴스 경유 기사는 실제 주소를 알 수 없어 출처 색상 타일로 대신 표시합니다.

## 인터넷 사이트로 공개 (GitHub Pages)
`node build-site.js` 가 수집·번역·상위 기사 요약을 돌려 `site/`(정적 HTML+JSON)를 만들고, `.github/workflows/site.yml` 이 3시간마다 자동 실행해 GitHub Pages 로 배포합니다.
- 이 폴더를 **별도 저장소의 루트**로 올리고 Settings → Pages → Source 를 “GitHub Actions” 로 지정.
- 사이트판 차이: “지금 업데이트”·소스 설정은 없음(서버가 자동 갱신), 스터디 보드는 **보는 브라우저(localStorage)** 에 저장, 핵심 요약은 상위 약 120건만 미리 생성(나머지는 요약문+원문 링크).
- 로컬 점검: `node build-site.js --no-collect` 후 `site/` 를 아무 정적 서버로 열기.
